Este proyecto es un sitio web básico desarrollado como parte de un curso de Front-End. Sitio: consiste en 3 páginas, página principal o index, Contacto y Carrito. HTML: Cada página del sitio está estructurada con HTML semántico y utiliza las etiquetas `
`, `
`, y `
` para organizar el contenido. En index se practicó sobre todo la navegabilidad de la barra de navegación y el acceso a niveles de carpetas y archivos. La página Contacto contiene un formulario que se conectó a formspree para recibir solicitudes. La página Carrito practica sobre todo la forma de mostrar `
` y distribuir imágenes de forma legible. CSS: Se usó CSS vanilla con los contenidos vistos hasta el uso de las propiedades de Flex, más lo aprendido de forma independiente, como el uso de :before para optimizar la vista del texto sobre la imagen de la página principal. Se aprendió a conectarse con fuentes externas como Google Fonts, Font Awesome para los íconos, aunque también se utilizaron íconos de forma local. Javascript: Aún no se utlizó Javascript
